# Internationalization (P5-#10)

Kargoyeri Studio iki dil destegi ile gelir: **Turkce (tr-TR)** default, **English (en-US)** opsiyonel.
Mimari `IStringLocalizer<SharedResource>` ve `.resx` dosyalari uzerine kuruludur.

## Mimari

```
src/Kargoyeri.Studio.Core/
├── Resources/
│   ├── SharedResource.cs         # marker tip
│   ├── SharedResource.resx       # Turkce (default culture)
│   └── SharedResource.en.resx    # English
└── Infrastructure/
    └── LocalizationServiceCollectionExtensions.cs
```

`Program.cs`:
```csharp
app.UseRequestLocalization(new RequestLocalizationOptions {
    DefaultRequestCulture = new RequestCulture("tr-TR"),
    SupportedCultures = new[] { new CultureInfo("tr-TR"), new CultureInfo("en-US") },
    SupportedUICultures = new[] { new CultureInfo("tr-TR"), new CultureInfo("en-US") }
});
```

`CookieRequestCultureProvider` ile kullanici secimi 1 yil saklanir.

## Kullanim

### Razor view
```razor
@inject IStringLocalizer<SharedResource> L

<h1>@L["Signup_Welcome"]</h1>
<button>@L["Action_Save"]</button>

<!-- Format args -->
<p>@L["Signup_CheckEmail_Body", Model.Email]</p>
```

### Controller / service
```csharp
public class MyController(IStringLocalizer<SharedResource> localizer)
{
    public IActionResult Index()
    {
        return Content(localizer["Brand_Tagline"]);
    }
}
```

### Data annotations
```csharp
public class SignupForm
{
    [Required(ErrorMessageResourceType = typeof(SharedResource),
              ErrorMessageResourceName = "Error_RequiredField")]
    [Display(ResourceType = typeof(SharedResource), Name = "Label_Email")]
    public string Email { get; set; }
}
```

## Yeni anahtar ekleme

1. `SharedResource.resx` icine `<data name="Key_Name"><value>Turkce</value></data>` ekle
2. `SharedResource.en.resx` icine ayni anahtar ile English degerini ekle
3. View/controller'da `@L["Key_Name"]` ile cagir

Anahtar konvansiyonu: `Modul_Aciklama` (Pascal-snake hibrit).

| Prefix       | Kullanim                          |
|--------------|------------------------------------|
| `Action_*`   | Buton/action label (Save, Cancel) |
| `Label_*`    | Form labelleri, kolon basliklari  |
| `Status_*`   | Domain status (Pending, ...)       |
| `Error_*`    | Hata mesajlari                     |
| `Success_*`  | Onay mesajlari                     |
| `Nav_*`      | Sidebar/navigation                 |
| `Auth_*`     | Login/logout/signup                 |
| `Signup_*`   | Self-service kayit akisi (P5-#4)  |
| `Billing_*`  | Faturalama (P4)                    |
| `Cert_*`     | Provider sertifikasyon (P5-#6)     |
| `Brand_*`    | Marka, layout, topbar              |

## Sweep / Audit

Hardcoded Turkce stringleri tespit etmek icin:
```pwsh
pwsh scripts/i18n-audit.ps1
pwsh scripts/i18n-audit.ps1 -Path src/Kargoyeri.Studio.Core/Views/Billing
pwsh scripts/i18n-audit.ps1 -Top 10
pwsh scripts/i18n-audit.ps1 -Json | ConvertFrom-Json | Where-Object { $_.File -like "*Billing*" }
```

Script tum `.cshtml` dosyalarini tarar; `@functions { ... }` C# bloklari ve Razor directive'leri (`@model`, `@using`, ...) atlanir. Ornek cikti:
```
i18n audit raporu
=================
Toplam ihlal: 89
Etkilenen dosya: 32

  13  src\Kargoyeri.Studio.Core\Views\Shipments\Detail.cshtml
   8  src\Kargoyeri.Studio.Core\Views\Shipments\Index.cshtml
   7  src\Kargoyeri.Studio.Core\Views\Workspaces\Index.cshtml
  ...
```

### Sweep tarihi (2026-05-06)
- Baslangic: **181 ihlal / 37 dosya**
- 1. tur (audit script `@functions` skip + bulk pattern replace): **143 → 105**
- 2. tur (alici/gonderici/buton metinleri): **105 → 89**
- Kalan 89 satir cogunlukla uzun KVKK metni, is akisi aciklamalari ve provider-spesifik notlar — el ile cevirilmek uzere P6'ya devredildi.

`_ViewImports.cshtml` global localizer:
```razor
@using Kargoyeri.Studio.Core.Resources
@using Microsoft.Extensions.Localization
@inject IStringLocalizer<SharedResource> L
```
Bu sayede her view'da `@L["Key"]` kullanilabilir, `@inject` tekrarina gerek yoktur.

## Bilinen sinirlar

- Resx dosyalari Visual Studio editor disinda da elle duzenlenebilir (XML)
- Cogul (plural) form `IStringLocalizer` icinde native degil — `Resource.GetString` + `string.Format` ile yontemli
- Tarih/saat/sayi format'lari `CultureInfo.CurrentCulture` ile otomatik handle edilir
- RTL diller (Arapca, Ibranice) henuz CSS direction switch'i icin destek yok — eklenebilir
